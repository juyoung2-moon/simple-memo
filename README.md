# simple-memo

실행: https://juyoung2-moon.github.io/simple-memo/ 에서 이메일·비밀번호로 회원가입 또는 로그인합니다. 메모를 입력하여 저장하고 목록에서 삭제합니다. 실습용으로 이메일 확인을 해제했습니다.

검증: 실제 사이트 첫 화면과 분홍색 디자인 확인. API에서 가입 즉시 세션 발급, 저장·조회·삭제, 로그아웃·재로그인 통과. 다른 사용자 메모 조회·삭제 차단 및 소유자 위조 추가 거절 통과. RLS 정책 확인. 테스트 메모는 삭제했고 임시 테스트 계정 2개는 남아 있습니다.

남은 검증: 실제 브라우저에서 회원가입 후 새로고침 시 로그인·메모 유지 및 전체 사용자 동작. 자동 검증은 API 수준이며 브라우저 전체 동작 검증을 대체하지 않습니다.
