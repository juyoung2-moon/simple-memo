# simple-memo

실행: https://juyoung2-moon.github.io/simple-memo/ 에서 이메일·비밀번호로 회원가입 또는 로그인합니다. 메모를 입력하여 저장하고 목록에서 삭제합니다. 실습용으로 이메일 확인을 해제했습니다.

검증: 실제 배포 브라우저에서 분홍색 화면, 로그인, 메모 저장·목록 표시, 새로고침 후 로그인·메모 유지, 일반 텍스트 표시, 메모 삭제, 로그아웃·재로그인을 확인했습니다. 이메일 확인 해제 전에 가입한 실습 소유 계정의 미확인 상태를 보완했습니다.

API에서 신규 가입 즉시 세션 발급, 다른 사용자 메모 조회·삭제 차단, 소유자 위조 추가 거절을 확인했습니다. memos 테이블 RLS 활성화 및 정책 확인 완료. 신규 가입 자동 로그인은 API로 검증했고 브라우저 회원가입은 미검증입니다. 확인용 메모는 삭제했으며 임시 테스트 계정 2개는 남아 있습니다.
